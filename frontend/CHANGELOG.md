# Changelog

## v1.0.0 — 2026-09-10

Initial frontend release targeting Persian STT backend v2.2.x.

- TypeScript-only React/Vite application
- Tailwind + shadcn CSS-variable design system
- light/dark/system theme
- Vazirmatn for local Persian content
- mobile bottom navigation and compact desktop sidebar
- intentionally simple Home workflow
- file browser with tags/descriptions and artifact actions
- human-readable job-state mapping including `retry_wait`
- REST network layer with Axios
- live job and system SSE clients
- statistics and settings pages
- standalone synchronized audio/subtitle player
- standalone RTL text viewer
- Vite development proxy and FastAPI static deployment workflow
